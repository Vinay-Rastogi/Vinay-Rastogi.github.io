# Vinay Rastogi Academic Website

This is a static GitHub Pages website. Upload the contents of this folder to the root of `VinayRastogi.github.io`.

## Main files
- `index.html` — homepage
- `research.html` — research projects and experimental platforms
- `publications.html` — publication list
- `activities.html` — service, collaborations and project experience
- `style.css` — all site styling
- `images/` — research and profile images
- `CV_Vinay_Rastogi.pdf` — CV

## How to update later
1. Open the file you want to edit on GitHub.
2. Click the pencil icon (Edit this file).
3. Change the text or image filename.
4. Click **Commit changes**.
5. GitHub Pages will rebuild the site automatically.

To add an image: open `images/` → **Add file** → **Upload files**, then reference it as `images/your-file.jpg` in the HTML.
